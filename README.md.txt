# Sunrise Café Ordering System

A web-based café ordering and management system built with PHP, MySQL, HTML, CSS, and JavaScript.

## Features

- Customer registration and login
- Browse the café menu
- Shopping cart and checkout
- Order tracking and order history
- M-Pesa payment integration
- Admin dashboard
- Menu and inventory management
- Supplier and purchase management
- Sales reports and customer reviews

## Requirements

- PHP
- MySQL or MariaDB
- Apache web server
- A PHP/MySQL-compatible hosting provider

## Local Setup

1. Install and start Apache and MySQL using XAMPP.
2. Create the required MySQL database.
3. Import the clean database SQL file.
4. Configure the database connection locally.
5. Configure M-Pesa credentials securely.
6. Open the application through your local web server.

## Security

Never publish database passwords, M-Pesa API secrets, passkeys, or customer information.
